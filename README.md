# Flaxgame website (GitHub Pages)

Static pages, no build step: the studio page, Prism Bloom's page and its privacy policy
(the URL given to Play Console). Published from its own public repo `flaxgame/flaxgame.github.io`;
this folder is the source. `.gdignore` keeps Godot from importing it.

- Public contact: sumanta.codex@gmail.com. Published at https://flaxgame.github.io/ (repo `flaxgame/flaxgame.github.io`, GitHub organization `flaxgame`).
- The privacy text mirrors `docs/PRIVACY_POLICY.md`. Update both, **before** a release that
  adds ads, purchases, analytics or cloud saves.
- `app-ads.txt` goes at the site root once AdMob is set up.
